# CropSense

**CropSense** is a simple and user-friendly web application designed to help farmers and gardening enthusiasts quickly assess the health of their crops. By selecting a crop type and an observed symptom, users receive an instant analysis of possible crop health issues along with practical recommendations.

The application focuses on clarity, ease of use, and accessibility, making it suitable for users with minimal technical background.

---

## Features

* Crop-based health assessment for commonly grown crops such as Rice, Wheat, and Cotton
* Symptom-based analysis including conditions like yellow leaves, brown spots, and wilting
* Instant identification of potential crop health issues
* Health scoring to indicate overall crop condition
* Actionable recommendations such as fertilizer use, fungicide application, and soil checks
* Clean, responsive, and visually calming user interface
* Validation to ensure users select both crop and symptom before analysis

---

## Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla)

---

## Usage

1. Select a crop from the available list
2. Choose the observed symptom affecting the crop
3. View the generated health analysis, score, and recommended actions

The application runs entirely in the browser and does not require any server-side setup.

---

## User Interface

* Responsive layout compatible with desktop and mobile devices
* Clean design with a calming background and overlay
* Simple navigation focused on usability and clarity

---

## Current Limitations

* Supports a limited set of crops and symptoms
* Rule-based logic without AI-driven prediction
* No backend or persistent data storage

---

## Project Purpose

CropSense serves as an introductory agri-tech project demonstrating how front-end web technologies can be used to build practical, user-focused tools for agriculture. It lays the foundation for future expansion into intelligent, data-driven crop monitoring systems.
